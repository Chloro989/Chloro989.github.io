数列と図形の複合問題

鋭角三角形ABCがある。数列 \(\displaystyle \frac {1}{tanA} \), \(\displaystyle \frac {1}{tanB} \), \(\displaystyle \frac {1}{tanC} \) が等差数列であるとき、 3点の長さの平方がなす数列 \(CA^2\), \(AB^2\), \(BC^2\) も等差数列であることを示せ。

数列と図形の複合問題 解答

3辺\(BC,CA,AB\)の長さをそれぞれ\(a,b,c\)とおく。さらに三角形\(ABC\)の外接円の半径を\(R\)とおく。
正弦定理より、\( \displaystyle \frac {a}{sinA} = 2R \)、すなわち、\( \displaystyle \frac {1}{sinA} = \displaystyle \frac {2R}{a} \)
余弦定理より、\( cosA = \displaystyle \frac {b^2+c^2-a^2}{2bc} \) であるから、
\( \displaystyle \frac {1}{tanA} \)=\( \displaystyle \frac {consA}{sinA} \)\( \displaystyle \frac {R(b^2+c^2-a^2)}{abc} \)
同様にして、
\( \displaystyle \frac {1}{tanB} = \displaystyle \frac {R(a^2+c^2-b^2)}{abc} \)
\( \displaystyle \frac {1}{tanC} = \displaystyle \frac {R(a^2+b^2-c^2)}{abc} \)
となる。
よって、数列 \( \displaystyle \frac {1}{tamA}\),\( \displaystyle \frac {1}{tamB}\),\( \displaystyle \frac {1}{tamC}\) が等差数列であるとき、すなわち、
\( \displaystyle \frac {2}{tanB} = \displaystyle \frac {1}{tanA} = \displaystyle \frac {1}{tanC}\) が成り立つとき、
\(\ \displaystyle \frac {2R(c^2+a^2-b^2)}{abc} =\) \( \displaystyle \frac {R(b^2+c^2-a^2)}{abc} =\) \(\displaystyle \frac {R(b^2+a^2-c^2)}{abc}\)
\( \therefore \) \(a^2+b^2 = 2b^2\)
すなわち、\(2CA^2 = AB^2 + BC^2\) となることから数列\(CA^2\), \(AB^2\), \(BC^2\) も等差数列である。

確率・ゲーム

\(n\)は\(4\)以上の整数、\(p\)は\( 0\lt p\lt 1 \)を満たす実数とする。
\(A\)と\(B\)の\(2\)人を含む\(n\)人が、次の(ルール)に従って\(2\)人ずつ合計\(n-1\)回の試合を行う。
ただし、どの試合においても、勝者と敗者は\(1\)人ずつであり、引き分けはない。
(ルール)
袋の中に\(1\)番のカード、\(2\)番のカード、\(\cdots\)、\(n\)番のカードが\(1\)枚ずつ合計\(n\)枚入っており、まず、\(n\)人が袋の中から\(1\)枚ずつカードを無作為に取り出す。
ただし、取り出したカードは袋には戻さない。
次に、\(1\)番のカードを取り出した人と\(2\)番のカードを取り出した人が1回目の試合を行う。
さらに、\(1\)回目の試合の勝者と\(3\)番のカードを取り出した人が\(2\)回目の試合を行う。
以下同様に、\(k\)回目の試合\(1\leqq k\leqq n-2\)の勝者と\((k+2)\)番のカードを取り出した人が\(k+1\)回目の試合を行う。
また、\(1\)回目から\((n-1)\)回目までの各試合において、勝敗の確率は次のようになるものとする。
\(\cdot\) \(A\)と\(B\)が試合を行う場合、一方がかつ確率は\(\displaystyle \frac {1}{2}\)である。
\(\cdot\) \(A\)と\(B\)のいずれでもない\(2\)人が試合を行う場合、一方がかつ確率は\(\displaystyle \frac {1}{2}\)であり、
他方がかつ確率は\(\displaystyle \frac {1}{2}\)である。
\(\cdot\) \(A\)または\(B\)のいずれか一方と、\(A\)と\(B\)のいずれでもない\(1\)人が試合を行う場合、
前者が勝つ確率は\(p\)であり、後者が確率は\(1-p\)である。
\((1)\) \(1\)回目の試合でAとBが試合を行う確率\(q_1\)、および\(2\)回目の試合で\(A\)と\(B\)が試合を行う確率\(q_2\)を求めよ。
\((2)\) \((n-1)\)回の試合のいずれかにおいて、\(A\)と\(B\)が試合を行う確率\(P\)を求めよ。

確率・ゲーム 解答

\(A\)が\(i\)番のカードを取り出し、Bが\(j\)番のカードを取り出すことを、
\((A, B) = (i, j)\)と表すことにする。
ただし、\(i, j\)はそれぞれ\(1\leqq i\leqq n\)、\(1\leqq j\leqq n\)、\(i\neq j\)を満たす整数である。
\((1)\) \(n\)人のカードの取り方は全部で\(n!\)通りあり、これらはすべて同様に確からしい。
\(1\)回目の試合でAとBが試合を行うのは、\((A, B)= \)\((1,2)= \)\((2,1)\).いずれの場合も
残り\((n-2)\)人のカードの取り出し方は\((n-2)!\)通りずつあるので、
\(1\)回目の試合で\(A\)と\(B\)が試合を行う確率\(q_1\)は、
\(q_1= \)\(\displaystyle \frac {2*(n-2)!}{n!}= \)\(\displaystyle \frac {2}{n(n-1)}\)
同様に、\(q_2= \)\(\displaystyle \frac {4p}{n(n-1)}\)
\((2)\) \(k\)回目\((1\leqq k\leqq n-1)\)の試合で
\(A\)と\(B\)が試合を行う確率を\(q{k}\)と定めると、求める確率\(P\)は、
\(P= \) \(q_1+ \)\(q_2+ \)\(\cdots + \)\(q_n-1 \)\(= \displaystyle \sum_{k=1}^{n-1}q_k\)
そこで、まず、\(q_k\)を求める。
\(q_1\)、\(q_2\)は\((1)\)で求めたので、\(k\geqq 3\)のときを考える。
\(k\)回目の試合で\(A\)と\(B\)が試合を行うには、
\(A\)または\(B\)が\((k+1)\)番のカードを取り出さなくてはならない。
そこで、\(B\)が\((k+1)\)番のカードを取り出す場合を考える。
(\(\mathrm{I}\)) \((A, B)= \)\((1,k+1)\)、\((2,k+1)\)のとき、
\(\displaystyle \frac {2}{n(n-1)}p^{k-1}\)
(\(\mathrm{II}\)) \((A, B)= \)\((m,k+1)\)\((3\leqq m\leqq k)\)のとき、
\(\displaystyle \frac {2}{n(n-1)}\)\( \cdot \displaystyle \frac {p+(1-2p)p^{k-1}}{1-p}\) \(\therefore \displaystyle \frac {2p}{n(1-p)}+ \)\(\displaystyle \frac {2(1-2p)(1-p^{n-1})}{n(n-1)(1-p)^{2}}\)

空間ベクトルと円錐

\(a\)、\(b\)を定数とする。\(O\)を原点とする座標空間内に\(4\)点 \(A(-4,4,0)\)、\(B(1,2,6)\)、\(C(-\frac{1}{3},a,b)\)、\(D(-\frac{1}{3},2,\frac{4}{3})\) がある。
\(3\)点\(O\)、\(A\)、\(B\)を通る平面\(\alpha\)上に、中心が\(\triangle OAB\)の重心\(G\)と一致し、半径が\(1\)の円がある。
この円を底面とし、点\(C\)を頂点とする直円錐は\(1\)つだけ存在し、これを\(S\)とする。
さらに、点\(D\)から\(\alpha\)に垂線を引き、\(\alpha\)との交点を\(E\)とする。
ただし、点\(D\)は平面\(\alpha\)に関して、点\(C\)と同じ側にある。

\((1)\) \(a\)、\(b\)の値をそれぞれ求めよ。
\((2)\) \(\cos\angle GCD\)の値を求めよ。また、点\(D\)が\(S\)の外部にあることを示せ。
\((3)\) 点\(E\)の座標を求めよ。また、\(S\)の側面上の点で、点\(D\)から最も近い点を\(H\)とするとき、線分\(DH\)の長さを求めよ。

空間ベクトルと円錐 解答

\((1)\) 点\(G\)は\(\triangle OAB\)の重心より
\(\displaystyle \vec{OG} = \frac{\vec{OA}+\vec{OB}}{3} = \frac{1}{3}(-4,4,0) + \frac{1}{3}(1,2,6) = (-1,2,2)\)
よって \(\vec{CG} = \vec{OG}-\vec{OC} = (-1,2,2)-(-\frac{1}{3},a,b) = (-\frac{2}{3},\, 2-a,\, 2-b)\)

平面\(\alpha\)上で中心が\(G\)である円を底面とする直円錐\(S\)の頂点が\(C\)であるから \(\vec{CG}\perp\alpha\)、
すなわち \(\vec{CG}\cdot\vec{OA}=0\) かつ \(\vec{CG}\cdot\vec{OB}=0\)
\(\vec{CG}\cdot\vec{OA} = \frac{8}{3}+4(2-a) = \frac{8}{3}+8-4a=0\) より \(a=\frac{8}{3}\)
\(\vec{CG}\cdot\vec{OB} = -\frac{2}{3}+2(2-a)+6(2-b)=0\) より \(a+3b=\frac{23}{3}\)、これに \(a=\frac{8}{3}\)を代入して \(b=\frac{5}{3}\)
\(\therefore\ a=\displaystyle\frac{8}{3},\ b=\displaystyle\frac{5}{3}\)

\(C\)、\(G\)、\(D\)は同一平面（円錐\(S\)の軸を含む断面）上にあるので、この断面で\(D\)や\(H\)の位置関係を図示できる。
\(G\)を原点、底面方向を横軸、軸\(CG\)方向を縦軸とする断面座標では、\(G=(0,0)\)、\(C=(0,1)\)、\(F=(1,0)\)、\(E=(\frac{2}{3},0)\)、\(D=(\frac{2}{3},\frac{2}{3})\)、\(H=(\frac{1}{2},\frac{1}{2})\)（線分\(CF\)の中点）となる。

\((2)\) \((1)\)より \(\vec{CG}=(-\frac{2}{3},-\frac{2}{3},\frac{1}{3})\)、\(|\vec{CG}|=1\)
\(\vec{CD} = \vec{OD}-\vec{OC} = (0,-\frac{2}{3},-\frac{1}{3})\)、\(|\vec{CD}| = \displaystyle\frac{\sqrt{5}}{3}\)
\(\vec{CG}\cdot\vec{CD} = \displaystyle\frac{1}{3}\)
よって \(\displaystyle \cos\angle GCD = \frac{1/3}{1\cdot \sqrt{5}/3} = \frac{1}{\sqrt{5}} = \frac{\sqrt{5}}{5}\)

ここで、\(S\)の側面上の点\(C\)以外の任意の点を\(P\)、直線\(CP\)と\(S\)の底面の円の交点を\(Q\)とすると、底面の半径が\(1\)、高さ\(|CG|=1\)であることから
\(\displaystyle \angle GCQ = \angle GCP = \frac{\pi}{4}\)
一方、\(\cos\angle GCD = \displaystyle\frac{1}{\sqrt5} < \cos\frac{\pi}{4} = \frac{\sqrt2}{2}\)なので
\(\displaystyle \frac{\pi}{4} < \angle GCD < \frac{\pi}{2}\)
よって点\(D\)は\(S\)の外部にある。

\((3)\) 点\(E\)は平面\(\alpha\)上の点であるから、\(\vec{OE}=k\vec{OA}+l\vec{OB}\)（\(k,l\)は実数）とおける。
\(\vec{OE} = k(-4,4,0)+l(1,2,6) = (-4k+l,\,4k+2l,\,6l)\)

\(\vec{DE}\parallel\vec{CG}\parallel(2,2,-1)\)より、\(E\)は点\(D\)を通りベクトル\((2,2,-1)\)に平行な直線上にあるから、
\(\vec{OE} = \vec{OD}+s(2,2,-1) = (-\frac{1}{3}+2s,\,2+2s,\,\frac{4}{3}-s)\)（\(s\)は実数）
これらを連立して解くと \(\displaystyle k=l=\frac{7}{27},\ s=-\frac{2}{9}\)
よって \(\displaystyle \vec{OE} = \left(-\frac{7}{9},\,\frac{14}{9},\,\frac{14}{9}\right)\)

\(\vec{GE} = \vec{OE}-\vec{OG} = (\frac{2}{9},-\frac{4}{9},-\frac{4}{9})\)、\(|\vec{GE}| = \displaystyle\frac{2}{3}\)
半直線\(GE\)上と\(S\)の底面の円の交点を\(F\)とすると、底面の円の半径が\(1\)より \(|\vec{GF}|=1\)
\(\vec{GF} = \displaystyle\frac{3}{2}\vec{GE}\)より \(\displaystyle \vec{OF}=\vec{OG}+\frac{3}{2}\vec{GE} = \left(-\frac{2}{3},\,\frac{4}{3},\,\frac{4}{3}\right)\)

\((2)\)より点\(D\)は\(S\)の外部にあるから、\(S\)の側面上の点で点\(D\)から最も近い点\(H\)は線分\(CF\)上にある。
線分\(CF\)上の点を\(I\)とおき、\(\vec{OI}=(1-t)\vec{OC}+t\vec{OF}\)（\(0\leqq t\leqq1\)）とすると、
\(\displaystyle \vec{OI} = \left(-\frac{1}{3}-\frac{t}{3},\,\frac{8}{3}-\frac{4t}{3},\, \frac{5}{3}-\frac{t}{3}\right)\)
\(\displaystyle \vec{DI} = \vec{OI}-\vec{OD} = \left(-\frac{t}{3},\,\frac{2}{3}-\frac{4t}{3},\,\frac{1}{3}-\frac{t}{3}\right)\)

線分\(DH\)の長さは\(|\vec{DI}|\)の最小値である。
\(\displaystyle |\vec{DI}|^2 = \frac{1}{9}\left\{t^2+(2-4t)^2+(1-t)^2\right\} = \frac{1}{9}(18t^2-18t+5)\)
\(\displaystyle |\vec{DI}| = \frac{1}{3}\sqrt{18t^2-18t+5} = \frac{1}{3}\sqrt{18\left(t-\frac{1}{2}\right)^2+\frac{1}{2}}\)
\(t=\displaystyle\frac{1}{2}\)のとき、すなわち\(I\)が線分\(CF\)の中点のとき、\(|\vec{DI}|\)は最小値 \(\displaystyle \frac{1}{3}\sqrt{\frac{1}{2}} = \frac{\sqrt2}{6}\)をとる。
\(\therefore\ DH = \displaystyle\frac{\sqrt2}{6}\)

整数と数列

\(p\)、\(q\)を正の整数とし、\(p \lt q\)とする。
\(a_n = p^n+q^n\)（\(n=1,2,3,\cdots\)）とすると、\(a_2=34\)である。

\((1)\) \(p\)、\(q\)の値をそれぞれ求めよ。
\((2)\) \(a_{n+4}-a_n\)が\(40\)で割り切れることを証明せよ。
\((3)\) \(\displaystyle b_n = \frac{1}{40}\left\{(p^n+q^n)(p^{2n}+q^{2n})-4\right\}\)（\(n=1,2,3,\cdots\)）とする。\(b_n\)が整数となる\(n\)の条件を求めよ。

整数と数列 解答

\((1)\) \(a_2=34\)より \(p^2+q^2=34\)
\(0 \lt p \lt q\)より\(p^2 \lt q^2\)であるから、\(2p^2 \lt 34\)、すなわち\(p^2 \lt 17\)
\(p\)は正の整数より \(p=1,2,3,4\)の可能性があり、それぞれ\(q^2=33,30,25,18\)となる。
この中で\(q^2\)が平方数になるのは\(p=3\)のとき\(q^2=25\)、すなわち\(q=5\)のみ。
\(\therefore\ p=3,\ q=5\)

\((2)\) \((1)\)より \(a_n=3^n+5^n\)
\(a_{n+4}-a_n = (3^{n+4}+5^{n+4})-(3^n+5^n) = 3^n(3^4-1)+5^n(5^4-1) = 80\cdot3^n + 624\cdot5^n\)
\(= 40\cdot2\cdot3^n + 40\cdot78\cdot5^{\,n-1} = 40\left(2\cdot3^n + 78\cdot5^{\,n-1}\right)\)
\(n\geqq1\)より\(2\cdot3^n+78\cdot5^{\,n-1}\)は整数であるから、\(a_{n+4}-a_n\)は\(40\)で割り切れる。

\((3)\) \(\displaystyle b_n = \frac{1}{40}(a_n\cdot a_{2n}-4)\)であるから、\(b_n\)が整数となるのは \(a_n\cdot a_{2n}\equiv4\pmod{40}\)のときである。
\((2)\)より、\(a_n\)を\(40\)で割った余りは周期\(4\)で繰り返すので、実際に計算すると
\(a_1=8\)を\(40\)で割った余りは\(8\)
\(a_2=34\)を\(40\)で割った余りは\(34\)
\(a_3=152\)を\(40\)で割った余りは\(32\)
\(a_4=706\)を\(40\)で割った余りは\(26\)
より、\(n\)を\(4\)で割った余りに応じて\(a_n\equiv8,34,32,26\pmod{40}\)（余り\(1,2,3,0\)のとき）を繰り返す。

また\(2n\)を\(4\)で割った余りは、\(n\)が奇数のとき\(2\)（よって\(a_{2n}\equiv a_2\equiv34\)）、\(n\)が偶数のとき\(0\)（よって\(a_{2n}\equiv a_4\equiv26\)）となる。

これらを\(n\)を\(4\)で割った余りごとにまとめると、
余り\(1\)（\(n\)奇数）：\(a_n\cdot a_{2n}\equiv8\times34=272\equiv32\pmod{40}\)
余り\(2\)（\(n\)偶数）：\(a_n\cdot a_{2n}\equiv34\times26=884\equiv4\pmod{40}\)
余り\(3\)（\(n\)奇数）：\(a_n\cdot a_{2n}\equiv32\times34=1088\equiv8\pmod{40}\)
余り\(0\)（\(n\)偶数）：\(a_n\cdot a_{2n}\equiv26\times26=676\equiv36\pmod{40}\)

\(a_n\cdot a_{2n}\equiv4\pmod{40}\)となるのは\(n\)を\(4\)で割った余りが\(2\)のときのみである。
\(\therefore\ b_n\)が整数となる\(n\)の条件は \(n\equiv2\pmod4\)（すなわち\(n=4k+2\)、\(k=0,1,2,\cdots\)）
